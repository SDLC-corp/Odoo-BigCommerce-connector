SETUP IN MINUTES

Connect BigCommerce to Odoo in 3 steps

No middleware, no third-party storefront apps - just your BigCommerce API credentials and you're live.

1 Create a Store API Account

In BigCommerce, go to Settings → API → Store-level API accounts and create an account with read/write scopes. Copy the three credentials:

Client ID
Store Hash
Access Token
2 Add the Store in Odoo

Open the connector, create a new BigCommerce store and paste your credentials. Then set your sync preferences:

Price list & default order status
Tax handling (separate line / Odoo default)
Match products by SKU (avoid duplicates)
Auto-import orders & auto-create invoices
3 Enable Webhooks & Sync

Register real-time webhooks in one click and run your first import. Supported webhook scopes:

Order Created Order Updated Order Status Product Created Product Updated

FAQs

Questions buyers ask us most.

Don't see yours? Email us at sales@sdlccorp.com and we'll get back same business day.

Which Odoo versions are supported?

Odoo 16, 17, and 18 - both Community and Enterprise editions. The connector is tested against fresh installs and common module combinations before each release.

What do I need on the BigCommerce side to connect?

Just a BigCommerce store and an API account (Store API Token). The connector uses the official BigCommerce V2/V3 REST APIs, so it works with every BigCommerce plan - Standard, Plus, Pro, and Enterprise - with no extra apps to install on your storefront and no theme changes required.

Is the sync real-time, or scheduled?

Both. Orders and inventory sync via BigCommerce webhooks (near-instant). A cron-based fallback runs on a schedule you control, so any record missed by a webhook is reconciled automatically. You can also trigger a manual full sync from the dashboard.

Can I connect multiple BigCommerce stores to one Odoo?

Yes. Add as many stores as you need. Each one keeps its own catalog, customers, orders, and currency settings inside Odoo, while sharing your single Odoo backend for fulfillment, accounting, and reporting.

What happens if a sync fails?

Failures are logged in the Sync Reports view with full error context - the request payload, the response, and a stack trace if applicable. Most can be re-triggered with a single click. For repeated failures, you can configure email or Slack alerts so your team is notified within minutes.

Is implementation help included?

Yes. Every purchase includes 10 hours of expert-led implementation (valued at US $500) - covering installation, configuration, field mapping, sync rules, and a guided first end-to-end test against your live store.

What about ongoing support?

90 days of email support is included with every license - bug fixes, configuration questions, and sync diagnostics. Extended support and SLA-backed plans are available; reach out to sales@sdlccorp.com for pricing.

What's your refund policy?

We follow the standard Odoo Apps Store policy: refunds are available within 30 days of purchase if the connector cannot be made to work in your environment. Reach out to support and we'll either resolve the issue or process the refund - whichever you prefer.
